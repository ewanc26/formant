# Built-in affect and style table (#125).
#
# Version 1, amplitudes in the PAD (pleasure/arousal/dominance) space. Each
# dimension is in [-1, 1] and 0 is the neutral point. The mapping lines are the
# documented data-driven route from those dimensions to the existing synthesis
# levers; the engine contains no emotion-specific code.
#
# A user table is layered over this one line by line: one new style, one changed
# coefficient or a whole replacement table can be shared without rebuilding.

schema 1
name formant-builtin
author Formant contributors
description Built-in continuous affect styles and emphasis levels
license AGPL-3.0-or-later
version 1.0.0

# Linear coefficients: arousal valence dominance.
# Scale levers are 1 + dot(coefficients, axes). Perturbation levers are
# dot(coefficients, axes), clamped only when a voice is rendered.
map pitch 0.12 0.02 0.06
map range 0.16 -0.02 0.04
map rate 0.22 0.00 0.05
map intensity 0.14 0.08 0.06
map jitter 0.45 -0.12 0.05
map shimmer 0.055 -0.02 0.01
map adduction -0.05 0.02 0.85
map effort 0.06 0.02 0.06

# SSML <emphasis> levels: pitch duration amplitude.
emphasis strong 1.22 1.30 1.28
emphasis moderate 1.12 1.15 1.14
emphasis reduced 0.90 0.85 0.88

# Named presets as PAD coordinates. Their levers are produced by the same
# mapping, so any midpoint between two presets is an audible interpolation.
style neutral 0.00 0.00 0.00
style calm -0.60 0.45 -0.25
style excited 0.80 0.70 0.50
style sad -0.70 -0.80 -0.55
style whispering -0.45 0.00 -0.80
style newsreader 0.05 0.10 0.35
