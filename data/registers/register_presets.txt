# Built-in overtone and subharmonic register presets (#140).
#
# Version 1. These are acoustic *simulations* of Mongolian and Tuvan
# throat-singing techniques, not samples or caricatures. Every value is an
# existing synthesis lever: a narrow resonance that emphasises one harmonic of
# the sine stack, and an optional deterministic second pulse series at half the
# fundamental. No samples, noise buffers or random state are involved.
#
# A user table layers over these presets register by register. Retuning one
# preset needs no rebuild and no code change.

# register NAME PARTIAL GAIN BANDWIDTH-HZ SUBHARMONIC-MIX SUBHARMONIC-PARTIALS
# A partial of 0 means "no pinched resonance"; a mix of 0 means "no second pulse".
register sygyt 6 12 20 0 0
register kargyraa 0 1 120 0.55 28

# voqs NAME LABEL -- VoQS-consistent descriptive labels.
# VoQS has no dedicated overtone symbol: sygyt keeps V (modal voice) and is
# described by its pinched-resonance levers below.
voqs sygyt V
voqs kargyraa V‼
