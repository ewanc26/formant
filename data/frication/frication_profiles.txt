# Built-in frication profiles (#101).
#
# Version 1. The unvoiced source is a fixed stack of deterministic sine
# partials; these rows decide how many partials it holds and where its spectral
# energy sits. A Lorentzian peak shaped from an attack centre/bandwidth to a
# steady centre/bandwidth is multiplied by the segment's existing formants.
# This is data, not synthesis code: no samples, filters or random buffers.
#
# A user table layers over this one profile by profile. Retuning one sound (or
# adding a new phoneme spelling) needs no rebuild and no code change.

schema 1
name formant-builtin
author Formant contributors
description Per-place frication envelopes for the unvoiced sine stack
license AGPL-3.0-or-later
version 1.0.0

# Global defaults: partials broadband-floor attack-seconds.
defaults 48 0.02 0.012
